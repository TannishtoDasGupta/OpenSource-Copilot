# Contributing

Thanks for helping improve OpenSource Copilot.

1. Fork the repository and create a feature branch.
2. Use Python 3.11 or newer.
3. Install `requirements-dev.txt` in a virtual environment.
4. Copy `.env.example` to `.env`; never commit real credentials.
5. Run `pytest` before opening a pull request.

Keep changes focused, add tests, update documentation, and never include API keys, tokens, personal data, or private repository content in fixtures. AI-generated suggestions must be clearly identified. No license has been selected yet; discuss licensing before contributing substantial code.
